# План реализации LogScope

**Цель:** потоковый анализ HTTP-журналов с ограниченной памятью и объяснимыми выводами.
**Архитектура:** чтение/разбор → фильтры → точные агрегаты + ограниченные структуры → отчёт.
**Технологии:** C17, стандартная библиотека Python для тестов и демонстраций.
**Спецификация:** SPEC.md.

Пользователь разрешил самостоятельную реализацию в новом изолированном репозитории.
Публикацией занимается ведущий агент. Локальный компилятор и сборки исключены из Git.

## Главные риски проверки
- Переполнения и границы строк: модульные тесты + повреждённый вход CLI.
- Вытеснения и коллизии таблицы: независимый точный подсчёт в Python.
- Большие скачки времени и опоздавшие записи: проверка окна и учёта исключённых записей.
- Пустые выборки: null вместо NaN/Infinity и деления на ноль.
- Ошибки ввода/вывода: достоверный код завершения, отсутствие ложного отчёта.
