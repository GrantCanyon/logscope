# Журнал выполнения — docs/PLAN.md

Решение: строгий TSV вместо Apache/JSON. Вход проще проверять; произвольные журналы
потребуют преобразования либо настройки сервера. Формат не выдаётся за универсальный.
Решение: новый изолированный репозиторий main выделен ведущим агентом; отдельное
рабочее дерево не требуется. Публикация только через ведущего агента.
Предварительная проверка: единый Record и единицы uint64 согласованы между модулями.
Этап 1: тесты написаны первыми; красный цикл подтвердил отсутствие logscope.h.
Компилятор: официальный Zig 0.17.0 Windows x86_64, SHA256 архива проверен по index.json:
b5663f69581dcf391293fbf16c06cb80d81d806545ce618b4d0bab7f0eb8c428.
Обнаружено: оптимизированная сборка Zig определяет NDEBUG; unit.c явно отменяет
его перед assert.h, чтобы проверки работали в любой конфигурации.

Этап 1: модульные контракты прошли (parser, histogram, atomic overflow, 10 000 sketch replacements, event-time ring). Сборка -Wall -Wextra -Wpedantic -Wconversion -Wshadow -Werror.
Этап 2: 18 сценариев CLI написаны; красный цикл — программа ещё не реализована.

Этап 2 завершён: фиксированный буфер читает двоичный поток, восстанавливается после
слишком длинных строк, считает причины и восемь номеров ошибок без исходного текста.
CLI применяет одинаковые фильтры к инциденту и baseline. Отчёт JSON v1 сохраняет
uint64, интервалы квантилей, границы Space-Saving, отсортированное окно и эвристику.
Человеческие сообщения, справка и текстовый отчёт — русский UTF-8.
Проверка: исходные 18 CLI-тестов прошли; добавлены проверки границ 8192/65536,
фильтров baseline, грамматики процентного порога и ошибок устройств Unix.
Модульные проверки повторно прошли. Unix IO-проверка на Windows пропущена;
запуск под GCC/Clang и sanitizers ещё предстоит в CI.

Этап 3: реализованы генератор синтетического инцидента, независимые контрольные
счётчики, автономный HTML без JavaScript/сетевых ресурсов и реальный измеритель
производительности/peak RSS. Проверки сначала показали отсутствие этих инструментов,

Добавлены CMake/Make и CI GCC/Clang + ASan/UBSan Linux, Clang Windows/macOS.
